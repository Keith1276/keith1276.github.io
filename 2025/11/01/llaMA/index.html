LLaMa论文解读

背景

Scaling law 指出：训练大模型时，模型大小和训练数据应该比例相等的缩放，如果模型大小加倍，训练数据也应该加倍。

[!NOTE]

补充说明：Scaling Laws的修正
实际上，现代扩展法则（如Chinchilla）表明，计算预算的最优分配并非严格等比缩放。例如，当总计算量（FLOPs）增加时，数据量的增长应快于模型参数的增长（如计算量翻8倍时，模型翻2倍，数据翻4倍）。

那么相似成本训练LLM，是大LLM配小数据好，还是大数据配小LLM？因为现实情况是数据量基本是定的。

本文作者认为小LLM配大数据更好，因为推理更快，研究者更多时候自己不去train,总是拿着训练好的LLM去推理，这种情况下，首选模型不应该是训练最快的，而是推理最快的LLM。

LLaMa的结果

沿着小模型配大数据的思想，训练了一个模型系列，参数量从7B到65B， 其中很notable的结果是13B模型在大多数的任务上比GPT-3要强

LLaMa预训练数据

预训练数据包含大约1.4T tokens，对于绝大部分的训练数据，在训练模型期间只见到过一次。Wikipedia和Books这两个数据集见过两次。

LLaVA

以LLaMa为backbone的多模态大模型

整体的任务是在LLaMa的基础上，将视觉embedding和 language Instruction综合起来给LLM,最后输出文字反馈。

Transformer基础

鉴于看到了相当多的work依旧在反复提到transformer，这里对transformer进行一个简单回顾

transformer是一个经典的seq2seq模型，相比其他，区别在于大量用到了self-attention模块

经典的RNN架构如下，缺点是难以平行话。今天这个计算必须从a1看到a4才能得到b4

所以今天有人提出了拿RNN做这个事情，但是这个CNN看起来缺点很明显，这个CNN只能考虑非常有限的内容。

但是大家都知道CNN可以扩大感受野，多尺度叠CNN就好了，好处就是可以平行化，不需要等其他filter算.

CNN的缺点是一定要叠很多层才能有长期咨询

Self-Attention

self-attention做的事情就是取代多尺度CNN干的事情。

每一个token都分别乘上三个不同的matix得到三个不同的vector

Q:query ： to match others

K:key : to be matched

V: information to be extracted

拿每一个Q去对每一个K做 attention

总而言之attention是吃两个向量输入，输出匹配度或者说相似度。在google的那篇文章中，使用的是scaled dot-product

d是q和k的dimension,因为他来做inner product了，所以两者d是一样的。但是为何处以根号d不处其他东西呢？ 在paper解释了为何除以这个。

然后做softmax计算相似度，再来乘以了v向量，就得到了最后一个向量，但是乍一看这个b1用到了全部的句子，所以最后做了一个mask去做这样一件事

qk想乘之后再乘v的意思其实是我要看一眼所有别的token的信息，不仅是要关注我和他的相似度，也要关注他自己所携带的信息，把信息加权回来，就是b了。

所以经过attention层之后，每一个token的embedding变成了聚合了其他token信息的embedding.

这里的attention有变形版本：Muti-head self-attention

原始paper说，做多头的话可能观察到的信息不太一样，有的想看全局，有的想看全部，这个其实觉得不太说得清。

啥是多头，为每个位置提供多个qkv版本。然后按照单头的计算，最后多个b直接concat，并且通过一个线性映射变成你想要的维度

Positional Encoding

仔细来看，上述过程中， 由于NLP的token有序性，需要模型进行考虑，但是上边的架构A打B B打A是等效的了

所以原文里边引入了一个位置编码，在原始的paper里边，需要在ai加上一个同维度的vector, 这样就可以了。

问题：为何是相加，为何不是concat。

说法很有意思，说在ai上加一个，等同于在x_i上concat一个one_hot编码然后经过映射。

LayerNorm and Batch Norm

batch Norm里边，假设有一个batch的数据，对该bacth 内不同data 的 dimension做norm

希望其u = 0 sigma = 1

Layer Norm 是对同一个数据，不同dimension让其变得统一，一般用于RNN类结构,因为这类模型一个batch的不同数据长度不一样不好batch norm。

[!NOTE]

有一些细节很有意思，刻板印象里transformer的内容是attention之后 经过add 再经过norm

但是当下认为输入attention之前做个norm, attn之后相加并且再经过一个norm会有比较好的效果

Pos encoding backbone已经加过一次了，就不用手工再加了
