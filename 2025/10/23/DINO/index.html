DINO

发表于2025-10-23|更新于2025-11-11
|浏览量:

参考文章：https://zhuanlan.zhihu.com/p/1940400858836742367

概览

传统深度学习依赖大量人工标注数据，而自监督学习通过从数据本身生成的监督信号，如图像块之间的关系、时序连续性，彻底摆脱了这个限制。为通用视觉表征学习铺平了道路。模型和数据集规模可以自由拓展，无需标注成本，适合大规模的训练。

核心创新点

  • 数据和模型规模协同优化
  • Gram锚定（为了解决patch后期和cls token相似度过高的问题）
  • 后处理策略（Post-hoc Strategies）
  • ViT骨干也进行了改进，使用了axial RoPE位置编码, 进行了位置编码正则化来避免位置伪影

术语概念解释

Vit输出的是密集特征，以用于下游任务。但是很有可能学到的每个patch的特征并不是很有独特性，即所有patch的区分度很小。

余弦退火调度：学习率调整策略，让学习率按照余弦函数的形式从初始值平滑衰减接近0. 在自监督尤其transformer广泛应用

相似度图(patch similarity Maps)： 计算图像所有局部块特征之间的相似性，生成一个对称矩阵或者热力图，反映模型对图像内部结构的理解程度。

现有自监督学习方法问题

自监督学习初衷是通过无约束的海量数据，训练任意大规模的高性能模型，但实际规模化应用中存在多重障碍。

存在模型不稳定与坍塌（Collapse）的情况：尽管DINO v2通过对比损失设计和正则化等方法缓解了部分问题，但是进一步扩大规模仍然会出现新的问题。例如，模型可能退化为输出常数特征（所有输入映射到相同点），完全丢失有用的信息。

[!NOTE]

所谓 自监督损失指的是对比损失：他的目标是为了不依赖标签，通过让统一图像不同视角产生相似的特征，让不同图像特征原理，从而学习出有语义的表示。DINO用的是一种无标签的知识蒸馏形式：有一个teacher网络，有一个student网络，两者结构相同但是参数不同。

对于同一个图片的两种不同增强方式：比如颜色扰动、模糊、crop,要求两者输出近似相等。

所谓坍塌或者退化指的就是 ，如果说模型学会了输出相同的向量：那么无论什么图片，两种输出都近似相当，但是没有学到任何有用的表示

DINO对此做了一系列的限制

所谓不稳定，因为teacher的参数是由student的参数的EMA（滑动平均）得到的，而student的参数还在剧烈的更新中，如果两者更新不同步，就会发生loss剧烈震荡。

规模化中的三大问题

  1. 无标注数据的效用问题：如何从无标注数据中筛选有用的数据，直接训练会降低模型效率？互联网爬取的原始数据包含噪声。
  2. 训练调度的不确定性：余弦退火调度需要预设总训练步数，但在超大数据规模上难以提前最优步数。
  3. 长周期训练中的特征退化，当模型参数达到VIT-Large（3B）且训练时间延长的时候，早期阶段特征质量提升，但后续相似度图显示特征逐渐退化（如过度平滑或者丢失局部细节）。图像块之间的相似度区趋于一致，失去判别性。

模型的任务定义

在DINO v2的基础上，希望进一步增加模型规模，以及拥有更好的稠密任务能力，就是不同patches的embedding可以很好用于语义分割、物体检测之类的任务。

数据获取

在17B图像数据矿上应用了三种策略的数据子集：

1.自动聚类平衡采样（Hierarchical k-means curation）:

  1. 使用DINO2计算图像向量

  2. 进行 分层聚类（hierarchical k-means）：

    • 聚成多层结构（5 层），每层的簇数量依次为：

    • 也就是从细到粗地组织视觉概念（fine → coarse hierarchy）；

  3. 应用 平衡采样算法（balanced sampling algorithm） 来保证每个视觉簇都被均匀采样。(也就是训练的时候各个类都能被均衡的使用到)

2.基于检索的任务相关数据（retrieval-based curation）

由于网络数据包含一些抽象艺术、表情包之类的图片，这些对于我们希望模型具有的能力是不符合的。所以从ImageNet等数据集中，使用DINOv2进行embedding，做相似度匹配，筛选出17B图像中对任务比较有用的图像.

3.公开数据集

这一部分直接用imageNet之类的数据集，是为了让模型在benchmark任务上有更好的能力，是第二个的补充吧看起来，因为毕竟不用这部分数据在benchmark上太难赢了。

其实还有一个对应的异质性，但是DINO v3最后用了这个方法。

最终训练集是三路并行数据的混合采样（mixture sampling）：

  • 模型训练时从三种来源中按比例取样；
  • 比例会动态调整（比如 early stage 更多来自 balanced data，后期更多来自 retrieval data）；
  • 目标是在“多样性（diversity）”与“相关性（usefulness）”之间取得平衡

训练阶段

Loss定义

DINOv3在 v2的基础上引入了patch之间的loss,一共包含四个部分：

[!NOTE]

一、全局目标 LDINO

  • 让不同增强版本的同一图像在 embedding 空间靠近
  • 关注整体语义（global features）

优化技巧： 使用 Sinkhorn-Knopp（SwAV 的分布式归一化算法）替代 DINO 的 centering，保证训练稳定性并避免 collapse。

二、局部目标 LiBOT

  • 来源： iBOT（Zhou et al., 2021）
  • 本质： Patch-level latent reconstruction
    • 模型学习 每个 patch 的特征
    • 让局部 patch embedding 能够重构或预测图像中其它 patch
  • 作用： 增强 局部感知能力，提升 dense prediction（分割、目标检测、深度估计）性能。

三、Koleo 正则化 LKoleo

  • 作用： 强制 batch 内的 feature 在 embedding 空间均匀分布
  • 好处：
    • 避免特征聚集在局部空间，提升表示的多样性
    • 改善分割、深度估计等 dense 任务性能
  • 权重： 论文中只加了 0.1，说明是一个轻量辅助正则。

关于Prototype方法的一些思考

为何使用可学习向量效果优于直接线性层输出分类结果？

假设在使用线性分类的前一层输出dimension为256，那么实际上如果直接分类，参数量为 21 *256 *1 * 1【所以1 *1 卷积就是全连接的线性层】

做prototype方法的优势在于L2正则化，抛却了长度的影响，从数学角度看，线性层是Wx+b,如果光为每个类创建向量做相似度匹配则是

直接是A x，甚至连bias都没有了。 所以L2正则和温度调控是基本要加的

所以在之后使用这个方法进行类的预测的时候，可以自然而然加上温控因子以及L2正则

实际运行结果来说，最后的mIOU反而降低了1%
